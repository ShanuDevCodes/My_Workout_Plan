# 🏋️‍♂️ My Workout Planner App

A clean and modern **Workout Planner app** built with **Jetpack Compose** in **Kotlin**. Plan your weekly fitness schedule, track your routines, and experience a responsive UI across themes and orientations.

> 🚀 *Still a Work In Progress — constantly evolving as I explore Clean Architecture, DI, testing, and modularization.*

---

## ✨ Features

- 🗓️ Plan workouts for each day of the week
- 🎨 Toggle Light, Dark, and System themes
- 🔁 State management via `ViewModel` & `State`
- 📦 Data persistence using `DataStore`
- 🧭 Type-safe Navigation Component
- 🔐 Firebase Authentication (WIP)
- 💡 AnimatedVisibility, LaunchedEffect, `rememberUpdatedState`
- 🧠 MVVM architecture with clean separation of concerns
- 📐 Responsive UI supporting both **Portrait** and **Landscape**

## 🛠️ Tech Stack

- **Jetpack Compose** — for reactive UI
- **Kotlin Coroutines & Flows** — for async state & logic
- **ViewModel + MVVM** — for UI logic separation
- **Room Database** — for local storage
- **DataStore** — for app settings persistence
- **Firebase Authentication** — for user login (WIP)
- **Navigation Component** — with type-safe routes
- **Material 3** — for modern components and theming
